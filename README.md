# Nova

Лендинг с личным кабинетом, подписками и реальной оплатой через ЮKassa.
Без сторонних зависимостей: только Node.js и встроенный `node:sqlite`.

## Возможности

- Регистрация и вход, пароли хранятся как scrypt-хеши, сессии в HttpOnly-cookie
- Личный кабинет: тариф, срок действия, лимиты
- Проекты: создание и удаление, лимит 3 проекта на бесплатном тарифе
- Подписки: «Старт» (0 ₽), «Про» (990 ₽/мес), «Бизнес» (4 990 ₽/мес)
- Оплата через ЮKassa: редирект на платёжную страницу, активация тарифа по вебхуку
- История платежей со статусами
- Защита от подбора пароля, проверка Origin, проверка суммы и владельца платежа

## Требования

- Node.js 22.5 или новее (используется `node:sqlite`)

## Запуск

```bash
npm start
```

Сайт будет доступен по адресу `http://127.0.0.1:3000`.

## Настройка оплаты

1. Скопируйте `.env.example` в `.env`.
2. Укажите `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` из личного кабинета ЮKassa.
3. Укажите публичный адрес сайта в `SITE_URL` (обязательно https для продакшена).
4. Добавьте HTTP-уведомления в ЮKassa на `https://ваш-домен/api/payments/yookassa`.
5. Перезапустите сервер.

Без ключей сайт работает, но покупка тарифов отключена и в кабинете показывается предупреждение.

### Переменные окружения

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | Порт сервера | `3000` |
| `HOST` | Интерфейс прослушивания | `127.0.0.1` |
| `SITE_URL` | Публичный адрес сайта | `http://127.0.0.1:3000` |
| `DATA_DIR` | Папка с базой | `./data` |
| `DB_PATH` | Путь к файлу SQLite | `./data/nova.db` |
| `YOOKASSA_SHOP_ID` | ID магазина ЮKassa | — |
| `YOOKASSA_SECRET_KEY` | Секретный ключ ЮKassa | — |
| `YOOKASSA_API_URL` | Адрес API ЮKassa | `https://api.yookassa.ru/v3` |

## API

| Метод | Путь | Описание |
| --- | --- | --- |
| `GET` | `/api/health` | Проверка работоспособности |
| `GET` | `/api/config` | Тарифы и доступность оплаты |
| `POST` | `/api/auth/register` | Регистрация |
| `POST` | `/api/auth/login` | Вход |
| `POST` | `/api/auth/logout` | Выход |
| `GET` | `/api/me` | Текущий пользователь и подписка |
| `GET` | `/api/projects` | Список проектов |
| `POST` | `/api/projects` | Создать проект |
| `DELETE` | `/api/projects/:id` | Удалить проект |
| `GET` | `/api/orders` | История платежей |
| `POST` | `/api/orders` | Создать заказ и получить ссылку на оплату |
| `GET` | `/api/orders/:id` | Статус заказа |
| `POST` | `/api/orders/:id/sync` | Перепроверить платёж в ЮKassa |
| `POST` | `/api/payments/yookassa` | Вебхук ЮKassa |

## Тесты

```bash
npm test
```

Тесты поднимают мок-сервер ЮKassa и проверяют регистрацию, лимиты проектов,
создание заказа, вебхук, идемпотентность и работу без ключей оплаты.

## Структура

```
server.js        сервер и API
index.html       лендинг
login.html       вход и регистрация
account.html     личный кабинет
styles.css       стили
api.js           клиент API и утилиты
tests/           проверочные сценарии
```

## Безопасность

- `.env` и папка `data` не должны попадать в репозиторий (см. `.gitignore`)
- Секретные ключи ЮKassa хранятся только на сервере
- Платёж подтверждается запросом к API ЮKassa, а не данными из вебхука
